# Password Vault

A secure application for storing and managing passwords.

## Features

- Add credentials (in-memory storage though; will improve in the near future).
- Exit the interactive menu.

## Security

- Not a secure app until now (will fix in the near future though).

> This project is provided as-is and is not a substitute for a professionally audited password manager.

- 'Cargo' and 'Rust' I guess.
